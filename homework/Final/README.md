# 期中作業－Basketball Shooting Game

## 專案名稱

🏀 Basketball Shooting Game

## 專案連結

GitHub：

[https://github.com/GaryChen111/_wp/tree/master/homework/midterm](https://github.com/GaryChen111/_wp/tree/master/homework/midterm)

ChatGPT 對話：

[https://chatgpt.com/share/69fd4dc9-2be8-8320-8afc-881fffd76ad6](https://chatgpt.com/share/69fd4dc9-2be8-8320-8afc-881fffd76ad6)

---

## 專案簡介

Basketball Shooting Game 是一款使用 HTML、CSS、JavaScript 與 Node.js 製作的投籃遊戲。

玩家可以控制籃球左右移動並進行投籃，在限時內挑戰最高分數，並上傳至排行榜與其他玩家競爭。

---

## 功能特色

* 🏀 投籃系統
* ⏱️ 倒數計時器
* 🔥 Combo 連擊系統
* 📱 手機版操作
* 🏆 本地排行榜
* 🌐 網路排行榜
* 🎨 美化介面
* ▶️ 開始畫面
* 🔁 再玩一次功能

---

## 使用技術

### 前端

* HTML5
* CSS3
* JavaScript
* Canvas API
* LocalStorage

### 後端

* Node.js
* Express
* CORS
* JSON File Storage

---

## 專案結構

```text
basketball-game/
│
├── index.html
├── style.css
├── script.js
└── server/
    ├── server.js
    ├── scores.json
    └── package.json
```

---

## 執行方式

### 直接執行

開啟：

```text
index.html
```

即可開始遊戲。

### 使用 Live Server

右鍵：

```text
index.html
```

選擇：

```text
Open with Live Server
```

---

## API

### 上傳分數

```http
POST /score
```

範例：

```json
{
  "name": "Player",
  "score": 100
}
```

### 取得排行榜

```http
GET /scores
```

回傳：

```json
[
  {
    "name": "AAA",
    "score": 120
  }
]
```

---

## 遊戲規則

1. 在時間限制內獲得最高分。
2. 投籃成功即可得分。
3. 連續得分可累積 Combo。
4. Combo 越高分數越高。
5. 時間結束即遊戲結束。
6. 可上傳分數至排行榜。
