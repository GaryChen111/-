# 🏀 Basketball Shooting Game

一款使用 **HTML + CSS + JavaScript** 製作的投籃遊戲。

玩家可以左右移動籃球並投籃，在限時內挑戰最高分數。

---

# 🎮 遊戲功能

- 🏀 投籃系統
- ⏱️ 倒數計時器
- 🔥 Combo 連續得分
- 🎵 音效播放
- 📱 手機版控制
- 🏆 本地排行榜
- 🎨 美化 UI
- ▶️ 開始畫面
- 🔁 再玩一次功能

# 🎮 操作方式

| 按鍵 | 功能 |
|---|---|
| ← → | 左右移動 |
| Space | 投球 |
| 手機按鈕 | 手機操作 |

---

# 🧠 遊戲規則

- 玩家需要將球投進籃框
- 每次進球都會增加分數
- 連續進球可累積 Combo
- Combo 越高，得分越高
- 時間結束後遊戲結束
- 排行榜會自動儲存最高分
